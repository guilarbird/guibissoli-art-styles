# Art Styles 100 - guibissoli.xyz

Coleção de 100 estilos de arte únicos criados para o site **guibissoli.xyz**, seguindo a paleta "Forensic Finance" e inspirados nos principais veículos de mídia crypto e tech.

## Paleta de Cores "Forensic Finance"

- **Turquoise**: `#14B8A6` (teal-500)
- **Citrine Gold**: `#EAB308` (yellow-500)
- **Dark Smoke**: `#0F0F0F` (near-black)

## Referências Visuais

As imagens foram inspiradas no aesthetic visual de:

- **The Block**: Gráficos de dados limpos, visualizações de blockchain, infográficos técnicos
- **Bankless**: Arte conceitual bold, ilustrações editoriais, design moderno
- **Unchained (Laura Shin)**: Fotografia editorial, retratos profissionais, layouts sofisticados
- **Pomp**: Minimalismo financeiro, charts e dados, aesthetic profissional
- **Gary Vee**: Energia vibrante, collages digitais, cultura visual contemporânea
- **Tech Media**: Interfaces futurísticas, visualizações de dados, aesthetic tech-forward

## Categorias

### 1. Data Visualization (20 imagens)
Gráficos, charts, dashboards, visualizações de blockchain, infográficos de dados financeiros, network graphs, heatmaps, candlestick charts modernizados, flow diagrams, métricas visuais.

**Localização**: `images/data_viz/`

### 2. Abstract Finance (20 imagens)
Formas geométricas representando finanças, padrões abstratos de mercado, composições minimalistas, texturas financeiras, ondas de volatilidade, fractais econômicos, gradientes de dados, formas líquidas representando capital.

**Localização**: `images/abstract_finance/`

### 3. Geographic/Global South (15 imagens)
Mapas estilizados, conexões globais, rotas de remessas, infraestrutura financeira emergente, paisagens urbanas do Sul Global, pontos de conexão geográfica, visualizações de mercados emergentes.

**Localização**: `images/geographic/`

### 4. Editorial/Portrait (15 imagens)
Silhuetas profissionais, retratos estilizados de líderes, composições editoriais, fotografia conceitual, figuras em ambientes financeiros, poses de thought leadership, aesthetic de revista premium.

**Localização**: `images/editorial/`

### 5. Technical/Infrastructure (15 imagens)
Arquitetura de blockchain, nodes e redes, servidores e infraestrutura, código visual, circuitos financeiros, camadas de protocolos, visualizações técnicas, diagramas de sistema.

**Localização**: `images/technical/`

### 6. Conceptual/Thought Leadership (15 imagens)
Ideias abstratas, metáforas visuais de inovação, futuro das finanças, conceitos filosóficos, transformação digital, disrupção visual, simbolismo de mudança, visões de futuro.

**Localização**: `images/conceptual/` *(em desenvolvimento)*
